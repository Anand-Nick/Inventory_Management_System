Welcome to Inventory Management System

The Inventory Management System is a web-based application developed using Flask, Python, HTML, CSS, and SQLite. It helps businesses efficiently manage their product inventory by providing an easy way to add, update, delete, and search products. The system maintains accurate stock records and helps prevent overstocking and stock shortages.

About This Project

This project provides a simple and secure solution for managing inventory in retail stores, supermarkets, pharmacies, warehouses, and small businesses. Administrators can organize products into different categories, upload product images, monitor stock levels, and generate an organized inventory database.

The application supports CRUD operations (Create, Read, Update, Delete), category-wise product management, image uploading, available stock tracking, low-stock monitoring, and out-of-stock reporting. The responsive interface makes the system easy to use on desktops, laptops, tablets, and mobile devices.
