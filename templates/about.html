About Inventory Management System

The Inventory Management System is a web application developed using Python, Flask, SQLite, HTML and CSS.

This system allows an administrator to manage products efficiently using CRUD (Create, Read, Update and Delete) operations.

Main Features

  • Admin Login
  • Add Products
  • Update Products
  • Delete Products
  • Product Image Upload
  • Search Products
  • Category-wise Product Display
  • Available Products
  • Low Stock Products
  • Out Of Stock Products
  • SQLite Database
  • Responsive User Interface
